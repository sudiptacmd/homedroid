# Homedroid 0.8.4

- Added **Tailscale** as a built-in module. The phone joins your tailnet in userspace mode (no
  root, and it doesn't take the phone's VPN slot), so every module is reachable at
  `http://<device-name>:<port>` from your own devices, and `ssh -p 8022 <device-name>` works
  from anywhere. Log in with the link the dashboard shows, or paste an auth key.
  Options: device name, HTTPS address for the dashboard on the tailnet (Serve) or the internet
  (Funnel), exit node, subnet routes, ACL tags, and a local SOCKS5/HTTP proxy so programs on
  the phone can reach your other devices. The `tailscale` command works in SSH shells.
- **Update from the dashboard:** Settings → App updates checks the latest GitHub release and
  downloads the APK for the phone's CPU, or takes an APK you upload from the browser. It only
  installs Homedroid signed with the same key. Android asks you to confirm on the phone (a
  notification opens the prompt); on Android 12 and later, later updates install without one.
  The server restarts on the new version by itself.
- **IPCam live view:** open a live viewfinder for any camera from the IPCam page, take photos
  and record video from it, and close it again; the phone turns the camera off when nobody is
  watching. The view keeps running while recording where the camera supports both at once.
- **Preview captures** in the dashboard: photos, videos (with seeking) and microphone
  recordings open in the page, and a new capture is offered for preview as soon as it's saved.
- Dashboard logins now survive app restarts and updates.
- **Setup guides** for Cloudflare Tunnel and Tailscale: step-by-step dialogs with links to the
  right pages of each admin console and the ports of the apps you have installed.

This is the last update you need to install by hand: from 0.8.4 on, update from the dashboard.
The first time, Android asks you to allow Homedroid to install apps.
