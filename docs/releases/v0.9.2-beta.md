# Homedroid 0.9.2 beta

**A redesigned phone app, with more control from the phone itself.** The overview, app
library and new settings screen use a consistent native interface with light and dark themes.

## New

- **A clearer overview.** Server status, battery, temperature, available memory and storage
  have their own cards. Start or stop the server, restart individual services, share the
  dashboard address and inspect service logs. The dashboard password is hidden until opened.
- **Phone settings.** Change startup behavior, SSH and web hosting, Tailscale and Cloudflare
  Tunnel setup, SSH authorized keys and the dashboard password. Password changes sign out
  existing browser sessions. Service changes restart active services; changes made while
  stopped take effect on the next start.
- **Appearance.** Follow the phone's theme, or choose light or dark. Bottom navigation
  connects Overview, Apps and Settings.
- **Mobile browser sidebar.** Dashboard page links now live in a collapsible sidebar
  opened from the top menu. It includes theme and logout controls, dismisses after navigation
  or tapping outside, and supports keyboard focus handling and Escape.
- **An app library.** Apps use readable cards with installation, storage and running status,
  and controls to install, open, enable, disable, remove and clear their data.
- **Control panel inside the app.** Open Files, AI and routines, deployments, cluster phones,
  camera controls, Terminal & SSH, modules and updates directly from the phone. The panel
  signs in through the existing local dashboard using an expiring session. It offers a
  start-server action when offline, supports document uploads and HTTP downloads, and opens
  external links in the browser. Phones with an outdated System WebView receive an update
  shortcut and browser option instead of a blank panel.
- **Phone setup shortcuts.** Battery optimization, app permissions, shared storage access
  and Android background-process guidance live in Settings.

Your installed apps, libraries and configuration are kept when updating. Camera and
microphone access still require enabling on the phone and granting Android permissions.
Generated browser-only downloads may need the browser dashboard to save.

This is a prerelease. The tag `v0.9.2-beta` uses the existing release workflow to build and
publish signed APKs for arm64, 32-bit ARM, x86_64 and universal, the AI runtime archives,
and `SHA256SUMS`.
