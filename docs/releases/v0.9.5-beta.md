# Homedroid 0.9.5 beta

**A redesigned app and dashboard, Dock mode, MacroPads and Homedroid Desktop, plus hosting,
CI/CD, databases and an MCP server.** The biggest release so far.

## New

### Look and feel
- **A redesigned phone app.** Material 3 with your wallpaper's colours on Android 12+, a clearer
  Overview (server status, dashboard address, vitals at a glance, services), an app library with
  install progress and **Update** buttons, and grouped settings. An **OLED black** theme and
  **burn-in protection**: an untouched Overview turns into a dim, drifting clock.
- **A redesigned web dashboard** you can make your own: several layouts (sidebar, icon rail, top
  bar, split view, focus and a kiosk mode for wall tablets), more than ten themes, font choices,
  a customizable overview and a command palette (Ctrl/Cmd+K). Your layout is saved on the phone,
  so it follows you to every browser.

### Dock mode
The server phone becomes a bedside or desk clock while it charges: five clock faces, live tiles
(server, battery, CPU, memory, storage, network, uptime, Tailscale, next alarm), a deep-red night
mode, and **OLED care** (pixel shift, layout swaps, dimming, screen-off hours). It can open when
you plug in, or run as the Android screen saver. The home-screen widget is redesigned in four
sizes, and a new clock widget opens the dock.

### MacroPads and Homedroid Desktop
- **MacroPads** turns the phone into a deck of big, customizable buttons, like a stream deck:
  hotkeys, media keys, typing, apps, URLs, commands and sequences on your computer, or calls to
  Home Assistant and other URLs from the phone. Profiles, pages, icons, colours and toggles,
  edited right on the phone.
- **Homedroid Desktop** is a tiny companion for your computer (about 1 MB on Linux) that runs
  those buttons and uses the **phone as a wireless webcam**: a virtual camera on Linux
  (v4l2loopback), an experimental one on Windows 11, and a local stream for OBS everywhere.
  It connects to the phone, never the other way round, so there are no firewall prompts.
  Its Camera panel sets zoom, torch, focus (tap to focus), exposure, white balance, rotation
  and mirroring, showing only what your phone supports, and saves presets. Downloads for
  Linux, Windows and macOS are attached to this release.
- **Make the deck yours:** backgrounds (colour, gradient or your own photo), fonts including
  your own, key corners and glow, and 88 icons or your own images, per deck, profile or page.

### Hosting and deployments
- **Custom domains** with ownership checks, per-domain headers and path routes.
- **Dynamic DNS** for DuckDNS and Cloudflare.
- A **firewall** for the dashboard and hosted sites, and **request logs**.
- Deployments gain **Go, PHP, Bun and Deno**, **ZIP or archive uploads**, **deploy hooks** for
  GitHub Actions, GitLab and CircleCI (and GitHub push webhooks), **build pipelines** with logs,
  and **rolling deploys and load balancing** across the phones in a cluster.
  See [deploy hooks](../guides/deploy-hooks.md).

### Mail and Wi-Fi
- **A mail server (Stalwart)** you can install from the app library, with a guided setup in the
  dashboard: the DNS records to copy, health checks, accounts and the settings for your mail
  apps. Most home internet providers block port 25, so the guide covers sending through a relay.
  See [mail](../guides/mail.md).
- **A Wi-Fi repeater:** the phone hosts its own Wi-Fi network and shares its connection through
  a built-in proxy; devices join with a QR code. Apps that ignore proxy settings won't use it.
  See [Wi-Fi repeater](../guides/wifi-repeater.md).

### AI, data and security
- A built-in **MCP server**, so Claude, Cursor or VS Code can check on the server and, if you
  allow it, restart services or redeploy. An approval-gated assistant in the dashboard uses the
  same tools. See [MCP](../guides/mcp.md).
- A **database manager**: browse SQLite databases (including your apps'), see the schema and
  relations, page through tables and run queries; plus a small JSON document store.
- **App lock** with a PIN or fingerprint, and secrets (dashboard password, tunnel and Tailscale
  keys, MCP token) **encrypted with the Android Keystore**.

## Fixed
- **App installs failing with "DNS: transient error"** (#11): Alpine no longer gets unusable DNS
  servers (IPv6 link-local), always has a public fallback, and you can set your own servers in
  Settings.
- **SSH port conflicts** (#12): the SSH port is a setting, and the web terminal works with SSH off.
- **Updating apps** (#7): installed apps can be updated from the phone or the dashboard; their
  data is kept.
- **Linux and macOS development setup** (#13): `tools/setup-dev.sh` and `tools/dev.sh`.
- Behind a Cloudflare tunnel, wrong passwords from one visitor no longer lock everyone out.

## Verified
- On an emulator: the new phone screens, Dock mode, MacroPads pairing and button presses reaching
  Homedroid Desktop, the webcam stream from the phone, and with the real Caddy: custom domains
  (routing, headers, verification), the web firewall, request logs, an upload deploy and a
  load-balanced deployment.
- Unit tests for the new pure logic (DNS, firewall, domains, DDNS, deploy hooks, pipelines,
  MCP, databases, Dock, burn-in, MacroPads, desktop pairing) and Homedroid Desktop's own tests.
- Not yet on real hardware: the Windows virtual camera, macOS input, and load balancing across
  two physical phones.

Your installed apps, libraries and configuration are kept when updating.

This is a prerelease. The tag `v0.9.5-beta` builds and publishes signed APKs for arm64, 32-bit
ARM, x86_64 and universal, the AI runtime archives, Homedroid Desktop for Linux, Windows and
macOS, and `SHA256SUMS`.
