# Homedroid 0.9.6.2 beta

**A fix for Tailscale not starting on some phones.** Reported in
[#17](https://github.com/sudiptacmd/homedroid/issues/17).

## Fixed

- **Tailscale crashed at startup on some Android 11+ phones** (reported on a Galaxy S21 Ultra with
  Android 15, One UI). The Tailscale log showed
  `netmon.New: route ip+net: netlinkrib: permission denied` and the module restarted again and
  again. Tailscale lists the phone's network interfaces when it starts, and Android blocks the
  call it used for that on some phones. Homedroid's Tailscale now falls back to the address list
  and per-interface calls that Android still allows. Phones where Tailscale already worked use the
  same path as before.

If Tailscale still doesn't start after updating, open its logs in Modules and
[send them with a new issue](https://github.com/sudiptacmd/homedroid/issues/new/choose).
