# Homedroid 0.9.6 beta

**Automated movies and TV on the phone: Prowlarr, Radarr, Sonarr and Jellyseerr, wired to
qBittorrent and Jellyfin for you.** Requested in
[#15](https://github.com/sudiptacmd/homedroid/issues/15).

## New

### Media automation
Four new apps in the app library:

- **Prowlarr** keeps your indexers (torrent sites) in one place and gives them to Radarr and
  Sonarr.
- **Radarr** finds, downloads and files movies; **Sonarr** does the same for TV and keeps
  watching for new episodes.
- **Jellyseerr**, now called **Seerr**, is a search and request page for you and your family.
  Sign in with your Jellyfin account.

Install the ones you want, in any order. Homedroid connects them once, as each one starts:
Radarr and Sonarr send downloads to qBittorrent and file them in `Movies` and `Shows`,
Prowlarr syncs its indexers to both, Jellyfin gets a Movies and a Shows library, and Seerr gets
Radarr and Sonarr as soon as you finish its setup wizard. There are no API keys to copy
between apps. Change anything you like afterwards; a connection you remove stays removed.

Prowlarr, Radarr and Sonarr are the official builds, checked against their SHA-256 before
installing. Their own updater is off; they update with Homedroid. **Sonarr is version 5,
Sonarr's own test release** (5.0.0.3041): Sonarr 4 is built on .NET 6, which can't start inside
Android's app sandbox, and running it on a newer .NET breaks its download queue. Sonarr 5 runs
on .NET 10 and worked in every test here. Sonarr and Seerr need a 64-bit phone. See the
[media automation guide](../guides/media-automation.md).

## Fixed
- **Security updates** for the Go libraries built into Caddy, cloudflared and Tailscale
  (`golang.org/x/net`, `klauspost/compress`, OpenTelemetry, `gobwas/ws` and
  `gorilla/websocket`). These were published after 0.9.4 and held up the 0.9.5 release build.
- Apps in Alpine now see the phone's memory size (`/proc/meminfo`, which Android hides
  from apps). Some programs need it to start.
- The release check now scans every bundled Go program before failing, so one run shows all
  problems.
- Homedroid Desktop's release upload waits long enough for the phone release to be built.
- The README no longer says the webcam camera controls and the MacroPads look are unfinished;
  both shipped in 0.9.5.

## Verified
- On an emulator (x86_64, 2.5 GB RAM): installing Jellyfin, qBittorrent, Prowlarr, Radarr,
  Sonarr and Seerr from the dashboard; every automatic connection, checked with the apps' own
  connection tests; Jellyfin's new Movies and Shows libraries; signing in to Seerr with
  Jellyfin; and a movie and a show requested in Seerr arriving in Radarr and Sonarr, monitored
  and filed under `/media/Movies` and `/media/Shows`. Hard links work in the media folder, so
  filing a finished download takes no extra space on internal storage. Sonarr 5 passed the
  same checks, including its download queue and the Prowlarr and Seerr connection tests.
- The connection helper runs against fake Radarr, Sonarr, Prowlarr, qBittorrent and Seerr
  servers in `tests/media-stack.test.cjs`: what it sends, that a second run changes nothing, and
  that removed connections stay removed.
- Not tested: an actual download through an indexer and its import into Jellyfin (no indexers
  were configured), or any of this on a real phone.

Your installed apps, libraries and configuration are kept when updating.

This is a prerelease. The tag `v0.9.6-beta` builds and publishes signed APKs for arm64, 32-bit
ARM, x86_64 and universal, the AI runtime archives, Homedroid Desktop for Linux, Windows and
macOS, and `SHA256SUMS`.
