# Homedroid 0.9.4 beta

**Ad blocking for your whole tailnet, Wake on LAN, network tools and Gemma 4.** This release
also carries everything from 0.9.3, which was tagged but never published.

## New

- **AdGuard Home.** Network-wide ad and tracker blocking with blocklists, statistics and a query
  log. Android won't let apps use port 53, so it answers on 1053, and Homedroid's Tailscale passes
  port 53 on the phone's tailnet address straight to it: add the phone as a custom nameserver in
  the Tailscale admin console and every device on your tailnet is filtered, at home or on mobile
  data. A setup guide covers that, routers that forward DNS to a port, and what DNS blocking
  can't do.
- **Wake on LAN.** Save your computers and wake them from anywhere the dashboard reaches:
  Tailscale, a Cloudflare tunnel or another phone in the cluster. The phone broadcasts the magic
  packet on its networks and shows whether a computer is on. Scripts and shortcuts can call
  `POST /api/wol/wake`.
- **Network tools.** A Network page with this phone's addresses, gateway, DNS and throughput;
  device discovery (mDNS, SSDP/UPnP and quick TCP probes); and ping, traceroute, DNS lookups,
  nmap port scans, HTTP checks, whois, iperf3 LAN speed tests and an internet speed test, all
  cancellable and with validated input. Live packet capture needs root, so it isn't included.
- **Gemma 4 E2B** joins the model catalog: Google's quantization-aware 4-bit build, which writes
  like a 2B model and is recommended on phones that run it quickly enough.
- **A website** at [sudiptacmd.github.io/homedroid](https://sudiptacmd.github.io/homedroid/),
  a new walkthrough (`homedroid-walkthrough.mp4`, attached), a rewritten README and issue forms
  for bugs, phone reports and app requests.

## Fixed

- **Updates from the dashboard work again.** Checking for updates asked GitHub for its "latest"
  release, which leaves out pre-releases, and every Homedroid beta is one. *Phones on 0.9.3 or
  older need to install this version once by hand* (or upload the APK under **Settings → App
  updates**); after that, updates work from the dashboard.
- **Videos and music play in the browser again** from Files.
- **Clusters:** phones behind a port forward or relay keep their real address instead of
  calling themselves, and leaving or pairing survives a sudden power cut.
- **Dashboard:** the mobile close button no longer shows on wide screens; empty `cdrom`, `floppy`
  and `usb` folders no longer appear in new media libraries.
- **Security:** Caddy's OpenTelemetry trace exporters are pinned to 1.45.0 (GO-2026-6505).

## Verified

- USB drives and microSD cards as network storage on a real phone; clusters across versions with
  copy and move both ways; AdGuard Home blocking through its DNS port; Wake on LAN packets and
  status; the network tools on an emulator.

Your installed apps, libraries and configuration are kept when updating.

This is a prerelease. The tag `v0.9.4-beta` uses the existing release workflow to build and
publish signed APKs for arm64, 32-bit ARM, x86_64 and universal, the AI runtime archives,
and `SHA256SUMS`.
