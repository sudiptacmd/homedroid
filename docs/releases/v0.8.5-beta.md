# Homedroid 0.8.5 beta

Camera views retain their last decoded frame while a new frame arrives, removing the
blank-frame flicker. Each camera has saved resolution, frame rate, rotation and motion
settings. Always-on monitoring can watch without saving or save video only during motion,
with configurable sensitivity, quiet time and maximum clip duration. A shared capture
storage allowance deletes the oldest completed captures to make room for new footage.

Authentication now limits failed attempts across login, Bearer APIs and password changes:
five failures per peer cause a 15-minute cooldown, with a shared 50-failure budget. Limits
survive restarts. Sessions expire after 24 hours, and logout/password changes revoke
terminal access too. Browser request protection, HTTP and WebSocket limits, SSH handshake
limits and security dependency upgrades strengthen access to the camera and other admin
features. See the [security review](https://github.com/sudiptacmd/homedroid/blob/main/docs/SECURITY-REVIEW-0.8.5.md) for details and boundaries.

After upgrading, log in again. For encrypted camera access use Tailscale HTTPS Serve or a
Cloudflare HTTPS tunnel. The direct LAN HTTP address remains unencrypted.

This is a prerelease: download its signed APK here or upload it through dashboard App
updates. The stable updater intentionally follows GitHub's latest stable release.
