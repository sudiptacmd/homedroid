# Homedroid 0.8.3

- Added **IPCam** as an optional module with its own dashboard page: per-camera photos
  and video, flash controls, microphone listening and WAV recording, capture downloads,
  and spoken announcements.
- Added **Settings** for changing the dashboard password and startup preference.
  Password changes sign out other browser sessions; the phone always shows the current
  password, even when the server is stopped.

- IPCam and Settings follow the new dashboard theme on desktop and mobile.
- The terminal and shell text use bundled JetBrains Mono, including offline.

Enable IPCam camera and microphone access in the phone app before using remote controls.
Capture does not wake the display or play app sounds. Android privacy indicators and
foreground-service notifications remain active; device-enforced sounds may still apply.
Video and microphone audio are saved separately. Enable access again after restarting.
