Homedroid Android home server FAQ.

Homedroid runs a home server on Android 10 or newer without root. This FAQ covers phone requirements, remote access, battery care, Jellyfin, webcam support, MacroPads and privacy.

Android home server requirements and answers

What is Homedroid?

Homedroid is a free, open-source Android home server app. Install one APK on an old Android phone to run Jellyfin, file storage, web apps and other services, then manage them from a browser on port 8800.

Does Homedroid need root or Termux?

No. Homedroid runs as an ordinary Android app. It bundles its own tools and uses proot for apps that need Alpine Linux. You do not need root, Termux or a replacement Android ROM.

Which phones can run Homedroid?

Android 10 or newer is required. APKs are available for arm64-v8a, armeabi-v7a and x86_64, plus a universal build. A 64-bit phone is recommended; Immich and local llama.cpp models need one. Leave storage for the apps and media you install.

Can I leave an old phone plugged in as a server?

Use a phone with a healthy battery and keep it ventilated. Stop using a swollen or damaged battery. Watch temperature under load, reduce heavy jobs if it gets hot, and use the manufacturer’s charge limit if available. Homedroid does not add charge limiting without root. Dock mode’s OLED care reduces static screen exposure; it cannot guarantee against burn-in.

How do I access the server away from home?

Use Tailscale for private access from your own devices, or Cloudflare Tunnel to publish a service at an HTTPS hostname. Both work behind CGNAT without router port forwarding. The direct LAN dashboard uses plain HTTP, so use it only on a trusted network.

How does an old phone compare with a Raspberry Pi?

A phone you already own includes a screen, camera, Wi-Fi and battery. A Raspberry Pi is a better fit for GPIO, USB radios and full Linux administration. Homedroid runs inside Android’s app sandbox, with proot overhead for Linux apps and no privileged ports or raw hardware access.

Is Homedroid free and open source?

Yes. Homedroid and Homedroid Desktop are free software under GPL-3.0. There is no Homedroid subscription. Optional cloud services, domains and hardware may have their own costs. Source and release downloads are on GitHub.

How do I use my phone as a webcam on Linux, Windows or macOS?

Pair Homedroid Desktop with the phone and enable Desktop webcam access on the phone. Linux uses v4l2loopback; Windows 11 has an experimental virtual camera. All platforms can send the local MJPEG stream at http://127.0.0.1:8891/stream to OBS. macOS and Windows 10 use OBS for virtual camera output.

How do MacroPads work?

MacroPads is a customizable button grid on the phone. The paired Homedroid Desktop program receives actions and runs hotkeys, media controls, text, apps and URLs on the computer. Shell commands are refused until you enable Allow commands on the computer. Phone-side HTTP buttons can call Home Assistant webhooks.

Does my data stay on the phone?

Files and local AI inference stay on your hardware. Cloud AI sends the prompts you choose to the configured provider; tunnels and remote access use the services you enable. The dashboard password, tunnel keys and other stored secrets are encrypted with Android Keystore. LAN HTTP is not encrypted.

Does Jellyfin use hardware transcoding on Android?

Homedroid connects Jellyfin to Android MediaCodec for H.264 and HEVC encoding where the phone supports them. Decoding, scaling, subtitle burn-in and HDR tone mapping still run in software. Performance depends on the phone and video format.

Can AdGuard Home use the normal DNS port?

Android does not let an unrooted app bind port 53, so AdGuard Home listens on 1053. Homedroid’s Tailscale integration forwards tailnet DNS port 53 to it. A router that supports a custom upstream DNS port can also use it.
