How to install Jellyfin and other server apps on Android

Install Jellyfin and other server apps on an old Android phone from Homedroid’s Modules page. Check the memory estimate first, then choose where the app’s media lives.

Before you start

  • A running Homedroid server and dashboard login.
  • Space for the app download and its library. For removable storage, connect a supported USB OTG drive or insert a microSD card.

How to install Jellyfin and other server apps on Android: step by step

  1. Choose an app in Modules

    Open Modules. Each card shows the app’s state, port and typical memory and CPU use. Jellyfin is a useful first choice for a media library.

  2. Install and open it

    Select Install on the app’s card. Wait for it to show running, then select Open. Finish the app’s own first-run setup and create its login.

  3. Choose the library location on the phone

    Use the app’s storage location picker in the phone app to select internal storage, a microSD card or a USB drive. Follow the picker’s explanation of what moves and the permissions it needs.

  4. Check the location and add files

    Back in the dashboard, check the storage location shown on the module card. Open Files to upload media to that location. Jellyfin and qBittorrent share the Media folder.

  5. Manage the app

    Use the card’s switch to turn the app off or on. Use Update when a newer app version is supplied by Homedroid. Clear data and Remove are destructive; read their confirmation before proceeding.

Typical memory and CPU

These are the estimates shown by Homedroid, from its module resource data. Memory is resident process memory; CPU describes use while busy. Actual use depends on the phone and workload.

Good to know and troubleshooting

  • The dashboard displays the library location; this guide uses the phone’s picker to change it. Settings and databases generally stay internal when media moves to removable storage.
  • FAT32 cannot hold files over 4 GB. On Android 10, app-owned folders on removable storage are deleted when Homedroid is uninstalled.
  • If a drive disappears, affected apps wait for it. Reconnect it before troubleshooting the app itself.
