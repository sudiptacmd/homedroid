How to share Android internet with Homedroid’s Wi-Fi repeater

Share an Android phone’s internet connection using Homedroid’s Wi-Fi repeater. Join its Wi-Fi Direct network, then set a proxy on the joining device. Browsers can use it without rooting the phone.

Before you start

  • An Android 10+ phone with Wi-Fi Direct, a running Homedroid server and an internet connection to share.
  • Grant Nearby devices permission on Android 13+, or Location permission on older Android versions. The dashboard cannot request this phone permission.

How to share Android internet with Homedroid’s Wi-Fi repeater: step by step

  1. Enable the repeater on the phone

    Open Settings → Services & connections → Wi-Fi repeater on the phone and grant permission. Once permission is available, you can also enable Wi-Fi repeater in dashboard Modules.

  2. Read the network details

    Open Wi-Fi repeater in the dashboard. Check the network name, passphrase, proxy address and whether the phone still has an upstream connection. Change the band or network settings if needed.

  3. Join the network

    On the second device, scan the QR code or join the listed network with its passphrase. If Android says it has no internet, choose to stay connected.

  4. Set the proxy

    In that device’s Wi-Fi or network proxy settings, use the address shown on the page and port 8282 for HTTP/HTTPS. Alternatively use the displayed PAC URL on port 8283, or SOCKS5 on 8284 in a compatible client.

  5. Test in a browser

    Open a website and check the repeater page’s connected devices, connections and transferred bytes. If the browser has separate proxy settings, configure those too.

Good to know and troubleshooting

  • Joining Wi-Fi alone is not enough: each client needs the proxy. Games, calls, VPN clients and apps that ignore proxy settings may not work.
  • Some phones drop their upstream Wi-Fi when Wi-Fi Direct starts and can then only share mobile data. Check the page before assuming traffic is using Wi-Fi.
  • The usual proxy address is 192.168.49.1, but use the one shown. Access to other devices on your home network is off by default.
