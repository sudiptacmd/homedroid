How to connect Claude, Cursor or VS Code to Homedroid with MCP

Connect Claude, Cursor or VS Code to your Android home server through Homedroid’s MCP page. Assistants can read status and logs with a separate token; you decide whether to let them restart services or redeploy apps.

Before you start

  • A running Homedroid server and an MCP client that can reach its dashboard address.
  • For access away from home, a private Tailscale connection or a suitable HTTPS tunnel. MCP is built in; no model download is needed just to connect an external assistant.

How to connect Claude, Cursor or VS Code to Homedroid with MCP: step by step

  1. Enable MCP

    Open MCP in the dashboard and turn on MCP server. It starts off. Leave Allow changes off for an initial read-only connection.

  2. Copy the endpoint and token

    Choose the address the assistant can reach. Copy the MCP token; it is separate from the dashboard password. The local endpoint is http://<phone-ip>:8800/mcp.

  3. Choose your client instructions

    Select Claude Code, Claude Desktop, Cursor or VS Code on the MCP page. Reveal the token to fill it into the displayed snippet, then copy the command or configuration to the client as directed.

  4. Test a read-only request

    Connect the client and ask which services are running. Check the tool list and audit entries in MCP to see what it called.

  5. Allow changes only when needed

    Turn on Allow changes if the external assistant should restart services, redeploy or wake computers. The dashboard’s own agent asks for approval before changes even when this option is on.

Good to know and troubleshooting

  • The older written guide calls the control Allow write and places MCP in Settings. The current dashboard has a separate MCP page and labels the control Allow changes.
  • Regenerate… replaces the token and disconnects clients using the old one. Update their configuration afterwards.
  • Homedroid does not publish a separate memory or CPU estimate for MCP. An optional local model used by the dashboard agent has its own AI memory cost.
