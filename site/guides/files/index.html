How to use an old Android phone as a NAS

Use an old Android phone as a NAS with Homedroid’s file browser and SFTP. Upload folders from your browser, preview media and reach supported USB drives or microSD cards through the phone.

Before you start

  • A running Homedroid server and a dashboard login.
  • For USB or SD storage, a supported drive attached to the phone and the storage access requested by Homedroid. For SFTP, your computer’s SSH public key.

How to use an old Android phone as a NAS: step by step

  1. Choose a location

    Open Files and select the storage location from Location. The page shows free space and the files in the current folder.

  2. Upload files or a folder

    Select Upload or Upload folder, or drop files onto the list. Use New folder to make a destination before uploading.

  3. Preview or download

    Open a supported image, PDF or media file to preview it. Use Download to save a file; a folder downloads as a ZIP. Share that downloaded copy with the intended recipient.

  4. Set up SFTP

    Enable SSH in Modules. Open Terminal & SSH, paste your public key under Add a public key and select Add key. Keep the private key on your computer.

  5. Connect from your computer

    Use sftp -P 8022 <phone-ip>, or the SSH port shown if you changed it. Accessible external volumes appear under /storage/<volume-id>. Use an SFTP client such as WinSCP or Cyberduck to browse them.

Typical memory and CPU

These are the estimates shown by Homedroid, from its module resource data. Memory is resident process memory; CPU describes use while busy. Actual use depends on the phone and workload.

Good to know and troubleshooting

  • This is browser and SFTP access; do not assume the phone advertises a Windows SMB share or anonymous public file links.
  • FAT32 has a 4 GB per-file limit. On Android 11+, All files access allows visible Homedroid folders; on Android 10, app-owned external folders are removed when the app is uninstalled.
  • If a volume is absent, check that Android sees it and that Homedroid has access. Keep another copy of files you cannot replace.
