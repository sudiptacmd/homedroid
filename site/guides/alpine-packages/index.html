How to install Linux packages on Android with Alpine apk

Install Linux packages on your Android home server with Alpine’s apk command. Homedroid’s browser terminal can open Alpine Linux directly, so you can add tools such as Git, Python or ffmpeg without root.

Before you start

  • A running Homedroid server, dashboard access and internet for package downloads.
  • Free storage for the packages. Their memory and CPU needs depend on what you run; there is no single estimate for arbitrary Linux software.

How to install Linux packages on Android with Alpine apk: step by step

  1. Open the terminal

    In the dashboard, open Terminal & SSH. Select Alpine Linux and then Connect.

  2. Install packages

    At the Alpine prompt, run apk add python3 git. To add ffmpeg too, run apk add ffmpeg. Wait for apk to finish before using the programs.

  3. Check the installed tools

    Run python3 --version or git --version to confirm the command is available. You can now use it from this Alpine shell.

  4. Reconnect later

    Use Disconnect when finished. The packages remain installed through server restarts and Homedroid updates. Over SSH, type alpine first to enter the same Linux environment.

Good to know and troubleshooting

  • If apk is not found, check that you selected Alpine Linux rather than Phone shell.
  • Alpine runs inside Android’s sandbox through proot. Software that needs privileged kernel access or ordinary Linux service management may not work.
  • The browser terminal does not require the SSH service. SSH’s roughly 10 MB estimate applies only if you also enable SSH for remote shell access.
