How to access your Android home server remotely

Reach your Android home server away from home with Tailscale, or publish a web app with Cloudflare Tunnel. Both connect out from the phone and work behind CGNAT without router port forwarding.

Before you start

  • A running Homedroid server with internet access.
  • For private access: a Tailscale account and Tailscale on the devices you connect from. For a public site: a Cloudflare account and a domain using Cloudflare DNS.

How to access your Android home server remotely: step by step

  1. For private access, turn on Tailscale

    In Modules, switch on Tailscale. Choose a device name, leave Auth key empty to use a login link, and select Turn on. Homedroid includes Tailscale; no separate Tailscale app is needed on the server phone.

  2. Sign in and connect

    Select Log in to Tailscale on the card, sign in and connect the phone to your tailnet. Approve the phone in the Tailscale admin console if your network requires it. Wait for Connected and its 100.x.y.z address.

  3. Open the phone from another device

    With Tailscale connected on your computer, open http://<phone-tailscale-ip>:8800. Use each app’s port for that app, such as 8096 for Jellyfin. MagicDNS also lets you use the device name.

  4. For a public site, create a Cloudflare tunnel

    In Cloudflare Zero Trust, create a Cloudflared tunnel. From the connector command, copy only the long token after --token. In Homedroid’s Modules, switch on Cloudflare Tunnel, paste the token and select Turn on.

  5. Add the public hostname

    In Cloudflare, add a public hostname or published application route. Select HTTP and the local service address, such as http://localhost:8080 for Web hosting. Use the app’s own port if publishing it directly.

  6. Test the intended access

    Try the private address from a device on your tailnet, or the public hostname from another connection. If publishing the dashboard at port 8800, put a Cloudflare Access policy in front of it and keep the dashboard password enabled.

Typical memory and CPU

These are the estimates shown by Homedroid, from its module resource data. Memory is resident process memory; CPU describes use while busy. Actual use depends on the phone and workload.

Good to know and troubleshooting

  • Use Tailscale for private admin tools. A Cloudflare hostname is public unless you add access restrictions.
  • Keep tunnel tokens and auth keys private. If the Tailscale phone is waiting for approval, check the admin console before changing Homedroid settings.
  • For private HTTPS, Tailscale settings offer Tailnet only (Tailscale Serve). Enable MagicDNS and HTTPS certificates in Tailscale first. Public internet (Tailscale Funnel) makes the address public.
