How to use a custom domain with an Android home server

Point your own domain at a website on your Android home server. Homedroid’s Domains page routes names to apps or deployments and checks that the name reaches the phone; Dynamic DNS and Firewall handle address updates and access rules.

Before you start

  • A domain whose DNS you can edit, a running Homedroid server and an app, deployment or folder to serve.
  • Web hosting enabled in Modules. Use Cloudflare Tunnel for public HTTPS without port forwarding, or arrange direct DNS and router forwarding.

How to use a custom domain with an Android home server: step by step

  1. Choose how the name reaches the phone

    For Cloudflare Tunnel, enable it and add your hostname with service http://localhost:8080. For direct access, point an A record at your public IP and forward router port 80 to phone port 8080.

  2. Add the domain

    Open Domains → Add a domain. Enter the full Domain, such as blog.example.com. Under Send visitors to, choose the deployment, app, folder or port, then select Add domain.

  3. Verify the route

    Select Verify on the domain card and follow the verification dialog, then Check now. If it fails, check the DNS or tunnel route and the selected destination before trying again.

  4. Keep a changing public IP current

    If using direct DNS with a changing address, open Dynamic DNS and add a DuckDNS or Cloudflare entry. Enter the domain or record and the provider token. Check its update result.

  5. Set access rules if needed

    In Firewall, add Allow or Deny rules for the intended addresses and scope. Test an address before saving. Keep your own dashboard address allowed; the page flags rules that would lock you out.

Good to know and troubleshooting

  • Direct forwarding to port 8080 reaches the phone over HTTP. Use a tunnel or a separate TLS endpoint for HTTPS.
  • Dynamic DNS does not remove CGNAT or open a blocked port. A tunnel is the alternative when inbound connections cannot reach home.
  • Firewall rules cover the dashboard and Caddy web sites, not all Android traffic. A tunnel running on the phone is always allowed, so use Cloudflare Access to restrict visitors coming through that tunnel. Verify checks that the domain reaches the phone.
