How to turn an old Android phone into a home server

Turn an old Android phone into a home server with Homedroid: install the APK, tap Start server and sign in from a browser. No root or Termux is needed.

Before you start

  • An Android 10 or newer phone with a healthy battery, free storage and an internet connection.
  • A computer on the same trusted network. A 64-bit phone is recommended; apps and models download separately.

How to turn an old Android phone into a home server: step by step

  1. Install Homedroid

    Download the APK from the Homedroid download page. Allow your browser or file manager to install it, then open Homedroid.

  2. Start the server

    Tap Start server. Copy the dashboard address, such as http://192.168.1.20:8800. Find the password under Dashboard login.

  3. Keep it running in the background

    On the phone, open Settings → Battery settings and allow background use. Follow the app’s guidance for your phone’s battery saver and Android 12+ process limits.

  4. Open the dashboard

    Enter the address in your computer’s browser and sign in with the dashboard password. On the phone itself, Open control panel opens the dashboard.

  5. Install your first app

    Open Modules in the dashboard. Pick one app, read its memory and CPU estimate, then select Install. Wait for installation to finish before opening it.

Good to know and troubleshooting

  • If the dashboard does not open, check the address shown on the phone and that both devices are on the same network. Guest Wi-Fi may isolate devices.
  • The direct dashboard address uses HTTP. Keep it on a trusted network; set up Tailscale for private remote access.
  • Keep the phone ventilated and use a manufacturer charge limit if available. Do not use a swollen or damaged battery.
