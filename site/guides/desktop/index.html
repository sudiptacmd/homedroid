How to pair Homedroid Desktop for MacroPads and an Android webcam

Pair Homedroid Desktop with your Android phone to run MacroPads shortcuts and use its camera on your computer. The dashboard creates a six-digit pairing code and lets you edit the button deck.

Before you start

  • Homedroid’s server running and Homedroid Desktop installed on a computer that can reach port 8800 on the phone.
  • For webcam use, access to the phone to grant camera permission. Linux needs v4l2loopback for virtual camera output; other platforms have the limits described below.

How to pair Homedroid Desktop for MacroPads and an Android webcam: step by step

  1. Create a pairing code

    Open Desktop & MacroPads in the dashboard and select Pair a computer. You can also pair from the computer icon in Tools → MacroPads on the phone.

  2. Pair the computer

    Run the command displayed under the code on your computer, or enter the phone address and code in Homedroid Desktop’s local control page at http://127.0.0.1:8891. The code works once and expires after five minutes.

  3. Edit the deck

    In Desktop & MacroPads, choose a profile and page. Select a key or an empty cell to edit its label, action and target computer. Save the deck to the phone.

  4. Try a key on the phone

    Open Tools → MacroPads and press the key. Keep Homedroid Desktop running so it can receive the action. Adjust shortcuts to match the computer’s operating system and application.

  5. Enable the phone camera

    On the phone, open the MacroPads computer panel, choose Enable Desktop webcam and grant camera permission. In Homedroid Desktop, choose the camera, resolution and frame rate.

  6. Use it in a call or OBS

    Select Homedroid Camera where virtual camera output is available. Otherwise use the companion’s local stream at http://127.0.0.1:8891/stream in OBS and start OBS Virtual Camera.

Good to know and troubleshooting

  • Shell commands require Allow commands on the computer. Pairing and camera frames over direct HTTP belong on a trusted LAN or Tailscale.
  • Windows 11 virtual camera and macOS input remain experimental. macOS and Windows 10 use OBS for virtual camera output. See the Desktop page for platform setup.
  • Only one webcam stream can use the phone camera. Stop IPCam live view, recording or monitoring before using Desktop webcam. Homedroid does not publish a separate memory or CPU estimate for Desktop or MacroPads.
