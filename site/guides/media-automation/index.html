How to run Radarr, Sonarr and Jellyseerr on Android

Run Radarr, Sonarr and Jellyseerr (now Seerr) on an old Android phone with Homedroid. Homedroid connects them to Prowlarr, qBittorrent and Jellyfin so a request can become a file in your library.

Before you start

  • A running Homedroid server, room for media and preferably at least 4 GB of RAM for the full set.
  • A 64-bit phone for Sonarr and Seerr. Use sources and media you have the right to download.

How to run Radarr, Sonarr and Jellyseerr on Android: step by step

  1. Install the media apps

    In Modules, install Jellyfin, qBittorrent, Prowlarr, Radarr, Sonarr and Jellyseerr. You can install them in any order. Wait for them to start.

  2. Create the app logins

    Use Open on the cards. Complete Jellyfin’s setup, and set usernames and passwords in Prowlarr, Radarr and Sonarr when they first ask.

  3. Add your indexers

    In Prowlarr, open Indexers → Add Indexer. Add a source you can use and save it. Homedroid links Prowlarr to Radarr and Sonarr; its indexers should appear under Settings → Indexers in those apps.

  4. Finish the Seerr wizard

    Open Jellyseerr, choose Jellyfin and sign in with your Jellyfin account. Use 127.0.0.1 for the server address and 8096 for its port. Choose the libraries to sync and finish the wizard. You can skip its Radarr and Sonarr step; Homedroid adds them afterwards.

  5. Request and follow a title

    Search in Seerr and select Request. Follow the queue in Radarr or Sonarr, then qBittorrent. Completed imports go to /media/Movies or /media/Shows and appear in Jellyfin.

Good to know and troubleshooting

  • Connections are made once. Homedroid preserves later edits and does not recreate connections you deliberately delete.
  • On drives without hard links, an import copies the media and can take twice the space while the torrent remains. Set seeding limits and review Remove Completed in the download client settings.
  • Sonarr 5 is a test release in this version. Update these apps through Homedroid. Use Tailscale for remote administration of Prowlarr, Radarr and Sonarr.
