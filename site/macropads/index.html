MacroPads: an Android stream deck alternative.

MacroPads turns an old Android phone into a custom button deck for your computer. Pair Homedroid Desktop to send hotkeys, media keys, text, app launches and commands over your network.

Build an Android stream deck around your shortcuts

Open Tools → MacroPads. Long-press a key to change its label, icon, colour and action. Make separate profiles for work, calls or media; add pages when the grid fills up. Grid sizes range from 2×2 to 6×8.

The starter deck includes copy, paste, undo, media keys and a mute shortcut. Shortcuts vary by app and OS, so edit them for your computer. A green button means the computer acknowledged the action, not that the microphone’s real mute state was measured.

Change the look per deck, profile or page: a colour, gradient or your own photo as the background, a font of your choice (including one you import), key corners and glow, and 88 built-in icons or your own images.

Pair once, keep the companion running

  1. Tap the computer icon in MacroPads, then Pair a computer.
  2. Download and run Homedroid Desktop.
  3. Enter the phone address and six-digit code in its local control page. Codes last five minutes. Up to eight computers can be paired.

Actions on the computer and the phone

Send hotkeys, single keys, Unicode text, media keys, mouse actions, URLs, files and app launches. Sequences combine desktop actions with short delays. Shell commands are blocked until Allow commands is enabled on the computer.

HTTP buttons run on the phone and can call Home Assistant webhooks. The starter Home Assistant button is disabled until you give it a real URL and enable it. Export deck JSON to back it up; exports can contain private webhook URLs.

Platform details that matter

Linux uses XTEST on X11, or uinput on Wayland with the right device permissions. Windows input needs matching administrator privileges to reach administrator windows. macOS needs Accessibility permission; that backend is experimental and untested on hardware.
