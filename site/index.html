RUNS ON YOUR PHONE
ZERO TELEMETRY

Your server reports
to you. Only you.

Nothing is collected. Homedroid has no analytics, no tracking, no crash reporting and no account to sign up for. It doesn’t send anything about you, your phone or your files to us or anyone else. There is no “us” server to send it to.

It only goes online for things you turn on. Downloading an app or an AI model you picked, your own Cloudflare Tunnel, Tailscale or dynamic DNS, notifications you set up, and checking GitHub for a newer version when the dashboard shows updates. That check is a plain request for the public release list, with no ID attached.

You can check. Homedroid is GPL-3.0 software with no third-party libraries in the app. Every connection it makes is in the source code. The apps you install keep their own settings: Homedroid turns off the usage reporting of Radarr, Sonarr and Prowlarr for you.

BEYOND THE APP LIBRARY

Need another tool?
apk add it.

Homedroid runs a full Alpine Linux, so thousands of packages from Alpine’s repository are one command away: Python, Node.js, git, ffmpeg, rclone, htop. Open Terminal in the dashboard, choose Alpine Linux and install what you need. Over SSH, type alpine first. Packages stay installed through restarts and Homedroid updates.

Find a package with apk search name, or browse pkgs.alpinelinux.org. Remove one with apk del name.

BEFORE YOU INSTALL

Good to know.

Real phones have quirks.
Here are the useful ones.

Read the full Homedroid FAQ ↗
What is Homedroid?

Homedroid is a free, open-source Android home server app. Install one APK on an old Android phone to run Jellyfin, file storage, web apps and other services, then manage them from a browser on port 8800.

Does Homedroid need root or Termux?

No. Homedroid runs as an ordinary Android app. It bundles its own tools and uses proot for apps that need Alpine Linux. You do not need root, Termux or a replacement Android ROM.

Does Homedroid collect any data?

No. Homedroid has no analytics, tracking, crash reporting or accounts, and sends nothing about you, your phone or your files anywhere. It only connects to the internet for features you turn on, such as downloading apps or models, your own tunnel, Tailscale or dynamic DNS, and checking GitHub’s public release list for updates. The source code is open, so you can verify every connection. More about privacy.

Which phones can run Homedroid?

Android 10 or newer is required. APKs are available for arm64-v8a, armeabi-v7a and x86_64, plus a universal build. A 64-bit phone is recommended; Immich and local llama.cpp models need one. Leave storage for the apps and media you install.

How much RAM does Homedroid need?

Homedroid itself uses about 75 MB. Each module adds its own share: SSH about 10 MB, Jellyfin 200–450 MB, Radarr and Sonarr about 200–300 MB each, Immich 0.8–1.5 GB. A 3 GB phone runs the file server, Jellyfin, qBittorrent and a few small services; the media automation set wants 4 GB, and Immich or a local AI model 6 GB or more. Modules you turn off use nothing. See every module.

Can I install other Linux software?

Yes. Homedroid includes Alpine Linux, so you can install packages from Alpine’s repository with apk. Open Terminal in the dashboard, choose Alpine Linux and run, for example, apk add python3 git. Over SSH, type alpine first. Packages stay installed through restarts and Homedroid updates. Watch it.

Can I leave an old phone plugged in as a server?

Use a phone with a healthy battery and keep it ventilated. Stop using a swollen or damaged battery. Watch temperature under load, reduce heavy jobs if it gets hot, and use the manufacturer’s charge limit if available. Homedroid does not add charge limiting without root. Dock mode’s OLED care reduces static screen exposure; it cannot guarantee against burn-in.

How do I access the server away from home?

Use Tailscale for private access from your own devices, or Cloudflare Tunnel to publish a service at an HTTPS hostname. Both work behind CGNAT without router port forwarding. The direct LAN dashboard uses plain HTTP, so use it only on a trusted network.

How does an old phone compare with a Raspberry Pi?

A phone you already own includes a screen, camera, Wi-Fi and battery. A Raspberry Pi is a better fit for GPIO, USB radios and full Linux administration. Homedroid runs inside Android’s app sandbox, with proot overhead for Linux apps and no privileged ports or raw hardware access.

Is Homedroid free and open source?

Yes. Homedroid and Homedroid Desktop are free software under GPL-3.0. There is no Homedroid subscription. Optional cloud services, domains and hardware may have their own costs. Source and release downloads are on GitHub.

How do I use my phone as a webcam on Linux, Windows or macOS?

Pair Homedroid Desktop with the phone and enable Desktop webcam access on the phone. Linux uses v4l2loopback; Windows 11 has an experimental virtual camera. All platforms can send the local MJPEG stream at http://127.0.0.1:8891/stream to OBS. macOS and Windows 10 use OBS for virtual camera output.

How do MacroPads work?

MacroPads is a customizable button grid on the phone. The paired Homedroid Desktop program receives actions and runs hotkeys, media controls, text, apps and URLs on the computer. Shell commands are refused until you enable Allow commands on the computer. Phone-side HTTP buttons can call Home Assistant webhooks.

Does my data stay on the phone?

Files and local AI inference stay on your hardware. Cloud AI sends the prompts you choose to the configured provider; tunnels and remote access use the services you enable. The dashboard password, tunnel keys and other stored secrets are encrypted with Android Keystore. LAN HTTP is not encrypted.

Does Jellyfin use hardware transcoding on Android?

Homedroid connects Jellyfin to Android MediaCodec for H.264 and HEVC encoding where the phone supports them. Decoding, scaling, subtitle burn-in and HDR tone mapping still run in software. Performance depends on the phone and video format.

Can AdGuard Home use the normal DNS port?

Android does not let an unrooted app bind port 53, so AdGuard Home listens on 1053. Homedroid’s Tailscale integration forwards tailnet DNS port 53 to it. A router that supports a custom upstream DNS port can also use it.

Can I run a mail server on an Android phone with Homedroid?

Yes, with caveats. Install Mail server (Stalwart) from the app catalog and follow the guided setup in the dashboard. It lists the DNS records to copy, runs health checks and shows the IMAP and SMTP settings for your mail apps. Many home internet providers block port 25, and some give you no public address, so you may need to send through a relay such as Mailgun or Amazon SES, or receive through a small VPS. Phones with 2 GB of RAM or less may struggle.

Can the phone share its internet connection like a Wi-Fi repeater?

Partly. The Wi-Fi repeater creates a Wi-Fi Direct network and runs a built-in proxy: HTTP and HTTPS on port 8282, SOCKS5 on 8284 and a PAC file on 8283. Join by scanning a QR code, then point the device's proxy setting at the phone. It is proxy-based, so browsers and many apps work, but games, calls, VPN clients and apps that ignore proxy settings do not. Speed is a fraction of your line speed.
